# Telco Customer Churn - Data Preparation Pipeline

## Dataset Information
* **Dataset Name:** Telco Customer Churn
* **Source:** [Kaggle - Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
* **Problem Type:** Binary Classification

## Project Summary
This repository contains a complete end-to-end data preparation and preprocessing pipeline built in Python for machine learning readiness. The project covers thorough Exploratory Data Analysis (EDA) with visualizations, hidden missing value identification, custom feature engineering, stratified train-test splitting, and leakage-free data preprocessing using scikit-learn's `ColumnTransformer` and pipelines.

## Repository Contents
* `data_preparation.ipynb`: The main Jupyter Notebook containing all steps (EDA, cleaning, feature engineering, preprocessing).
* `WA_Fn-UseC_-Telco-Customer-Churn.csv`: The raw dataset used for this project.
* `requirements.txt`: List of required Python libraries.
* `README.md`: Project documentation.
